# Zero-DiDCE: Low-Light Image Enhancement

A deep learning-based system for enhancing low-light images using Zero-DCE and CNN-based feature extraction techniques. The project aims to improve image brightness and visibility while preserving important visual details.

## Features

- Low-light image enhancement using Zero-DCE
- CNN-based feature extraction and fusion
- Squeeze-and-Excitation attention mechanism
- Image enhancement evaluation
- Streamlit-based user interface
- User authentication and feedback functionality

## Technologies Used

- Python
- PyTorch
- OpenCV
- Streamlit
- NumPy

## Project Structure

The project includes modules for:
- Model implementation and enhancement
- Data loading and preprocessing
- Low-light image testing
- User authentication
- Feedback management
- Application interface

## Team Project

This project was developed as a collaborative team project. The repository contains the team's implementation and development work.
